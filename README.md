# flappy bird:
this is a game made by using html css and js. the player controls the bird and tries to pass throught the gap between pipes and without touching them.
the main goal is to get the highest score.

# description:
This project is a recreation of the classic Flappy Bird game using html css and js The player controls the bird by clicking or pressing a key to make it fly upward The bird falls automatically due to gravity so the player must control its movement carefully to pass through the gaps between the pipes.

# Installing
Download or clone this repositor
Extract the project files if they are in a ZIP file
Open the project folder in VS Code or another code editor
Make sure all html css and  js and image files remain in their correct folders.


# playing the game

Open the project folder.
Open the index.html file.
Run it using a web browser or Live Server in VS Code
Start the game and control the bird to pass through the pipes
Try to get the highest score without hitting the pipes or ground.
